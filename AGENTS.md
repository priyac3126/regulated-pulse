# Website conventions

## Blog posts

Do NOT create a new folder per post (e.g. `post-title/index.html`). Keep all blog posts as single HTML files in the project root (e.g. `post-title.html`) or an existing posts directory. Never create a new directory for a new post or update.

When the user provides an article, publish it EXACTLY as given: do NOT change a single word — no edits to wording, grammar, spelling, punctuation, or phrasing of the article text itself. Only handle formatting, markup, and layout around it.
